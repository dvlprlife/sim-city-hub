# Acme

An example production workspace — a placeholder for one of your own repositories. Point this building's `absolutePath` at a real project and treat it like production code.

When working in this building:
- Read the project's entry config first (e.g. `package.json`, `README`, build files) to understand its language, framework, dependencies, and structure.
- Follow the conventions and patterns already in the codebase — match what's there rather than introducing new ones.
- Extend existing code rather than rewriting it; keep changes small and reviewable.
- Preserve compatibility: don't break public interfaces, stored data, or anything dependents rely on.
- Build, and run the relevant tests, before considering a change complete.
