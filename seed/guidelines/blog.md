# Blog

A personal blog — markdown content plus a static/React site.

When working in this building:
- Most work is content: blog posts written in markdown. Match the existing post structure and front-matter (title, date, tags, etc.) exactly when adding or editing posts.
- For site/code changes, follow the project's existing React and build conventions (check `package.json` first) and keep components small and clean.
- Write in the author's voice — clear, direct, developer-friendly. Don't overwrite personality when editing.
- Don't fabricate facts, quotes, or stats in posts; flag anything that needs verification.
- Build or preview the site to confirm content renders and links work before finishing.
- This is a personal project: it's fine to iterate quickly, just keep it tidy.
