# Suburbs

This is the personal district: side projects, web apps, blogging, and general research. Lighter-weight than Downtown.

When working in this city:
- Default to modern JavaScript/TypeScript and React conventions. Match the project's existing framework, versions, and patterns first.
- Ship fast, but keep it clean: small focused components, readable code, sensible names, and the obvious edge cases handled.
- Don't over-engineer or add heavy dependencies for small needs — prefer the platform and what's already installed.
- Run or build the project to confirm a change works before calling it done.
- Keep secrets and API keys out of the client and out of the repo.
- It's fine to move quickly and iterate here — this is your own turf, not a regulated production system.
