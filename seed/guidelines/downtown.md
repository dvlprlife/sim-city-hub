# Downtown

This is the production district: your main, serious projects, where changes are reviewed and care matters.

When working in this city:
- Read the project's conventions first — its README, config, and the surrounding code — and match what's already there rather than introducing new patterns.
- Treat this as production code. Prefer small, focused, reviewable changes over sweeping ones.
- Protect compatibility: don't remove or repurpose public interfaces, data shapes, or stored data carelessly.
- Be careful around sensitive areas — data integrity, money, permissions, and anything users depend on.
- Lean on the specialists: design before building, test before merging, and review before shipping.
